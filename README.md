# Proyecto #1 'Lubricentro - La Esquina'

Este es el repositorio del sitio web informativo desarrollado para Lubricentro La Esquina. El proyecto se ha construido utilizando **Astro**, **Tailwind** y **JavaScript** con el objetivo de ofrecer una experiencia en línea moderna, rápida y atractiva para los clientes potenciales de el Lubricentro La Esquina.
